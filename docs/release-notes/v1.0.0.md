Left Right Audio Balancer 1.0.0 is a complete overhaul built from the ground up for maximum speed, minimal resource use, and a modern Fluent desktop look.

### Major Changes

- **Near-Zero RAM Usage:** Memory dropped from over 200 MB down to under **1 MB** (~0.8 MB). You can leave it running forever without noticing it.
- **Tiny Standalone App:** File size shrank from 75 MB down to just **~390 KB**. No .NET runtime, installer, or extra libraries required—just download and run.
- **Fluent Desktop Card:** Crisp rounded card with smooth sliders, live audio level meters for each ear, and automatic Bluetooth device detection.
- **Fixed Bluetooth Balance:** Built-in one-click fix for Bluetooth headphones that hide per-ear volume.
- **Zero Idle CPU:** Smooth animations when in use, and drops straight to 0.0% CPU when idle.

### Install

Download `LeftRightAudioBalancer.exe` and run it. Self-contained: no runtime to install.

The exe is unsigned, so Windows may warn on first run. Verify the SHA256 above if you want to check the download.
